# FAMILY SMART

יומן משפחתי בעברית: לוח מבחנים, אימונים, תוכנית הכנה, כרטיסיות תרגול ומרחב הורים.

- האתר: `index.html` (נבנה מ-`src/` ו-`sync/` עם `python3 tools/build_web.py`).
- שמירה וסנכרון: Firebase של המשפחה (התוכנית החינמית). ההגדרות ב-`config.js` ציבוריות מטבען; ההרשאות נקבעות ב-`firestore.rules`.
- בלי סיסמאות: ההורה המנהל/ת נכנס/ת עם Google במחשב, וכל מכשיר אחר מתחבר עם קוד חד-פעמי.
- הקוד ציבורי ולכן אין בו שמות או מידע על המשפחה. כל הנתונים נשמרים ב-Firebase ונגישים רק למכשירים מחוברים.
